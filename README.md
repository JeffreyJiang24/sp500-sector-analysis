# S&P 500 Sector Analysis

## Overview
Analysis of S&P 500 sector performance from 2013-2018 using SQL and Tableau.

## Tools Used
- SQL (SQLite) — data cleaning, joins, and analysis
- Tableau — interactive dashboard and visualizations

## What I Analyzed
- Annual returns by sector and year
- Sector volatility (average daily price swings)
- Post-COVID recovery trends by sector

## Key Findings
- Information Technology and Consumer Discretionary were the top performing sectors overall
- Energy and Utilities consistently underperformed relative to other sectors
- Significant sector rotation visible between 2015-2017

## Files
- sector_returns.csv — annual return % by sector and year
- sector_volatility.csv — average daily price swing by sector and year
- covid_recovery.csv — sector performance during 2019-2021
